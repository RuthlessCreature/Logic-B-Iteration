# Research Charter

## 1. 问题

现有 Logic A 是一套以“昨日涨停体系 + 次日核心确认 + 高位情绪/板块证据”为中心的人工超短交易框架。

它的优势是符合真实盘面决策方式；缺点是部分概念依赖人工判断，无法直接进行大样本、无歧义的历史复盘。

本项目要回答：

1. Logic A 在严格可成交假设下，历史期望收益是否为正？
2. 它的利润究竟来自哪些市场状态、板块结构和候选类型？
3. 亏损主要发生在哪些可识别的失败模式？
4. 能否通过版本化迭代，获得比 B0 更稳健的规则？
5. 新规则在未参与设计的未来数据上是否仍然成立？

## 2. 目标

建立一个可重复运行的研究系统，使每个版本都有：

- 完整规则定义；
- Point-in-time 输入；
- 可复现交易记录；
- 可成交性模拟；
- 收益与风险指标；
- 失败案例；
- 与前版本差异；
- 升级/拒绝理由；
- blind holdout 表现。

## 3. 非目标

- 不预测单只股票“必涨”。
- 不使用未来数据解释历史买点。
- 不通过无限调参寻找最好看的历史曲线。
- 不把涨停后无法成交的价格当成真实买入价。
- 不根据事后题材强弱重新定义当天的“核心”。
- 不以少数大牛股覆盖系统性亏损。

## 4. 关键研究原则

### 4.1 Point-in-time

任意交易决策只能读取该决策时间之前已公开、已产生、且数据系统当时可获得的信息。

每个字段应尽可能包含：

- event_time
- available_time
- source
- revision/version

### 4.2 Execution first

信号与成交必须分离：

```text
signal -> order intent -> order eligibility -> fill model -> position -> exit
```

“选中了涨停股”不等于“买到了涨停股”。

### 4.3 Human vs Proxy

B0-H 保留人工语义；B0-P 负责机器化。

如果 B0-P 与人工判断长期偏离，优先修代理定义，而不是直接用收益结果反推标签。

### 4.4 Version discipline

每次实验必须回答一个明确问题，例如：

- 是否应过滤中位高度？
- 是否应加入板块涨停宽度门槛？
- 是否应对昨日最高板断板后的空间压缩加惩罚？
- 是否应过滤一字加速后的首次大分歧？
- 是否应把高位“死尸池”负反馈量化为开仓闸门？

禁止一次性叠加十几个条件后宣布“B7 很强”。

## 5. 成功标准

项目成功不等于得到某个夸张年化收益。

成功定义为：

1. 两年历史可稳定重放；
2. 每笔交易可追溯到当时的证据；
3. B0 能被机器近似并与人工复盘对照；
4. 至少发现若干稳定的正/负贡献因子；
5. 新版本通过多个时间窗口，而非只在单一区间有效；
6. 能给出收益范围及不确定性，而不是单点神话数字。

## 6. 失败条件

出现以下任一情况，应停止继续堆规则并重新审查：

- blind holdout 明显失效；
- 大部分利润来自少于 5 笔异常交易；
- 轻微改变交易成本后策略从正变负；
- 参数稍微移动就完全失效；
- 可成交模型一真实化，收益大幅坍塌；
- 样本不足却持续增加规则复杂度；
- 人工判断无法稳定复现。
